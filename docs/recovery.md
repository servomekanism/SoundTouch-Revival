# SoundTouch 20 SM2 recovery

Keep the [live baseline and original firmware identification](compatibility.md) available. The inspected unit matches the SoundTouch 20 Series III SM2 route. Its original Bose firmware file is available and its size and CRC32 were checked. Obtain explicit approval before any uninstall, reset, or firmware upload.

1. **Speaker is still starting.** Allow the installer to reach a final result. Preserve any error details and check both the Bose and STR API with the read-only probe after the restart settles. If the router assigned a new IP, use that address.
2. **Wi-Fi is down and the speaker still boots.** Connect the speaker to the router by Ethernet and use the wired DHCP address for the read-only probe. Once reachable, check its status and decide whether to restore Wi-Fi or uninstall STR. [Bose Series III rear connectors](https://support.bose.ca/en-CA/article/st20iii-speakerwireless-understanding-the-rear-inputs---ka08c000000hgkvaae)
3. **STR is reachable and needs to be removed.** Follow **Speaker settings → Remove STR** in the pinned desktop app. Remove any STR install stick first to prevent reinstall from that stick. Save the preset data privately before removal. Verify the Bose API and the expected native functions after the app completes its restart. The original TuneIn entries may still depend on services that ended with Bose's cloud. [STR removal workflow](https://github.com/JRpersonal/streborn/blob/v1.8.2/desktop-app/frontend/src/views/settings/actions.js#L312) · [Bose service notice](https://www.bose.com/soundtouch-end-of-life-row)
4. **STR is unavailable and the unit still supports USB boot.** The pinned app documents **Prepare a USB stick instead** as a fallback. Keep it distinct from Bose's firmware USB drive and decide whether repair or removal is the intended outcome before using either. [STR USB fallback](https://github.com/JRpersonal/streborn/blob/v1.8.2/docs/ARCHITECTURE.md#5b-first-install-usb-stick-fallback-and-recovery)
5. **Bose firmware repair is necessary.** Use the exact SM2 package in the compatibility report and a Bose-documented Series III update route that remains available on the unit. Bose describes USB-A drive, Micro-B service cable, and speaker Setup Wi-Fi routes. An interrupted write or a wrong hardware image can make a working recovery interface inaccessible. A same-version image has not been demonstrated to recover this unit from a failed boot. [Bose Series III manual update options](https://support.bose.ca/en-CA/article/soundtouch-20-iii-updating-the-software-or-firmware-of-your-product)

If none of the documented interfaces works, recovery is unverified for this unit.
